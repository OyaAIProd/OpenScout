## 📚 Overview

OpenScout is a Perplexity-inspired answer engine. It transforms a single question into a well-researched, cited response. With features such as web search, retrieval, and LLM synthesis, OpenScout offers a streamlined experience in a lightweight Streamlit application.

- **Quick Answers:** Get instant, cited answers to your questions.
- **User-Friendly Interface:** Designed for everyone, no tech skills required.
- **Powered by Advanced Technologies:** Utilizes web search and generative AI.
- **Easy Setup:** Simple installation process.

## 📝 System Requirements

To run OpenScout, ensure your system meets the following requirements:
